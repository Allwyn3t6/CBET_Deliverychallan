Delivery Challan Management System
A comprehensive web-based Delivery Challan and Equipment Receipt Record system for the Center for Biomedical Equipment Testing & Calibration (CBET). This application allows seamless creation of delivery challans with automatic data storage to Google Sheets.

🌟 Features
1. Complete Delivery Challan Form
Challan Information: Unique challan number with date

Client Details: Client information with optional email

Equipment Tracking: Dynamic equipment entry with accessories and condition notes

Service Request: Multiple service options (Calibration, Testing, Maintenance, Repair)

Delivery Details: Transport information with authorized delivery personnel

Client Acknowledgement: Digital signature and acceptance section

2. Smart Features
✅ Dynamic Equipment Entry: Add unlimited equipment items

✅ Auto-filled Signatures: Delivery person signature auto-fills from dropdown

✅ Responsive Design: Works on desktop, tablet, and mobile devices

✅ Print Functionality: Clean print layout for physical copies

✅ Form Validation: Required field validation with visual indicators

✅ Automatic Date/Time: Pre-filled with current date and time

3. Google Sheets Integration
✅ Automatic Data Storage: All submissions saved directly to Google Sheets

✅ Complete Data Capture: All form fields including equipment details

✅ Timestamp Tracking: Automatic submission timestamp

✅ Error Handling: Robust error handling and user feedback
